## A sample of my Current Projects: 

### Interactive Breathing & Mindfulness App 
(start: summer 2025)

**Tech:** React, Hooks, Tailwind CSS, requestAnimationFrame  
**Focus:** UI animation, state management, accessibility, UX

A responsive breathing application that guides users through timed breathing cycles using smooth, visually calming animations. The app supports both normal breathing and box breathing, emphasizing precision timing and intuitive user feedback.

**Key features:**
- Smooth inhale, hold, and exhale animations driven by JavaScript timing
- Normal and box breathing modes
- Phase-aware UI with dynamic sizing and color transitions
- Clean React architecture leveraging hooks and refs
